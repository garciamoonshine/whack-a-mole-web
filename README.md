# 🐹 Whack-a-Mole Web

A fun browser-based Whack-a-Mole game with multiple difficulty levels, combo multipliers, and animated moles.

## Features
- 9-hole grid with randomised mole appearances
- 4 mole types with different point values
- Combo multiplier for consecutive hits
- 3 difficulty levels (Easy / Normal / Hard)
- 30-second countdown timer
- Score pop-up animations on hit
- Best score persistence via localStorage
- Touch and click support

## How to Play
1. Choose difficulty and click **START GAME**
2. Click/tap moles as they pop up
3. Score as many points as possible in 30 seconds!

## Mole Types
| Emoji | Points | Notes |
|-------|--------|-------|
| 🐹 | 10 | Normal mole |
| 👹 | 20 | Fast mole |
| 👾 | 30 | Bonus mole |
| 🔫 | 5 | Bomb — avoid! |

## Tech Stack
- HTML5
- CSS3 (keyframe animations)
- Vanilla JavaScript
